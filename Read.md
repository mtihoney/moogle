# Omoogle — go live

Random video + text chat with strangers worldwide. No phone number, no email, no account.
The Node server introduces two waiting browsers; **all video, audio and chat then flow directly
peer-to-peer over WebRTC**. No messages or media are stored.

## Run locally
```bash
npm install
npm start
# open http://localhost:8080  (open a second tab to match with yourself)
